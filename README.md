
3D N-Body Gravity Simulation (OpenGL)

A real-time 3D N-body gravitational simulation built in C++ using the OpenGL 3.3 Core Profile. It features a central 3D sphere surrounded by Saturn-style orbital particle rings.

Key Features:
- N-Body Physics
- Saturn-Style Multi-Rings
- Instanced Rendering Pipeline
- Distance-Based Color Gradients
- Interactive 3D Camera

Controls:
- W / S — Move camera forward / backward
- A / D — Strafe 
- camera left / rightMouse — Look around (Free-look yaw & pitch)
- ESC — Close the simulation window

Tech Stack & Dependencies:
- Language: C++Graphics API: OpenGL 3.3 Core Profile
- Windowing & Input: GLFW
- Function Loading: GLADMath 
- Library: GLM (OpenGL Mathematics)
